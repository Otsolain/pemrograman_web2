# Pemrograman Web 2

Repository ini berisi kumpulan tugas dan latihan untuk mata kuliah **Pemrograman Web 2**. Setiap folder merepresentasikan materi dari satu pertemuan, disusun secara berurutan mulai dari dasar PHP hingga integrasi database MySQL.

## Teknologi

- **PHP** (server-side scripting)
- **MySQL** (database, diakses via `mysqli` dan `PDO`)
- **HTML / CSS** (markup dan styling)
- **XAMPP** (lingkungan pengembangan lokal)

## Cara Menjalankan

1. Pastikan **XAMPP** sudah terinstal dan service **Apache** serta **MySQL** aktif.
2. Salin atau clone repository ini ke dalam direktori `htdocs` XAMPP.
3. Untuk file yang memerlukan database, import file `.sql` yang tersedia melalui **phpMyAdmin**.
4. Akses melalui browser di `http://localhost/<nama-folder>`.

Setiap folder memiliki file `README.md` tersendiri yang menjelaskan isi dan tujuan dari masing-masing latihan.
