### Materi Query

1. **Kelola Database** — `CREATE DATABASE`, `CREATE TABLE`, `ALTER TABLE`, `CREATE USER`, `GRANT`
2. **Query Satu Tabel** — `INSERT`, `UPDATE`, `SELECT`, `DELETE`
3. **Query Multi-Tabel (JOIN)** — `INNER JOIN`, `LEFT JOIN`, `JOIN` dengan fungsi agregat `COUNT()`
