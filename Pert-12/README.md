# Pertemuan 12 — CRUD: Update & Delete

Latihan operasi UPDATE dan DELETE pada database, serta menampilkan data artikel.

## Daftar File

| File | Deskripsi |
|---|---|
| `koneksi.php` | Koneksi ke database `artikel_db` |
| `artikel.php` | Menampilkan daftar artikel dari database |
| `latih1.php` | Latihan query `UPDATE` — mengubah usia mahasiswa |
| `latih2.php` | Latihan query `DELETE` — menghapus data mahasiswa |
| `artikel_db.sql` | Script SQL untuk membuat database dan tabel artikel beserta data contoh |
| `lat_dbase.sql` | Script SQL untuk membuat database dan tabel mahasiswa (dipakai latih1 & latih2) |
