# Pertemuan 13 — Form Input Data dengan Validasi

Latihan form input data mahasiswa lengkap dengan validasi sisi server dan pengecekan duplikasi NIM.

## Daftar File

| File | Deskripsi |
|---|---|
| `download-script-form-input-data.php` | Form input data mahasiswa (NIM, nama, jurusan, alamat, telepon) |
| `action-input-data.php` | Proses form: validasi data kosong, cek NIM duplikat, dan insert ke database |
| `koneksi-tutor.php` | File koneksi ke database `db_mahasiswa` |
| `mahasiswa.sql` | Script SQL untuk membuat database dan tabel mahasiswa |
