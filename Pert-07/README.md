# Pertemuan 07 — Array Lanjutan

Latihan fungsi-fungsi array lanjutan: pencarian, pemecahan, dan penggabungan.

## Daftar File

| File | Deskripsi |
|---|---|
| `latihan4.php` | Pencarian elemen array dengan `in_array()` |
| `latihan5.php` | Memecah array ke variabel terpisah dengan `list()` |
| `latihan8.php` | Menggabungkan elemen array menjadi string dengan `join()` / `implode()` |
| `latihan9.php` | Mengecek apakah variabel bertipe array dengan `is_array()` |
| `latihan10.php` | `in_array()` dengan mode strict (`TRUE`) untuk pencocokan tipe data |
